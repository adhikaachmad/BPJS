# 1. Pendahuluan

## 1.1 Tujuan Dokumen

Dokumen ini merupakan buku panduan penggunaan aplikasi **Sistem Pembelajaran BPJS Kesehatan (PENTAS)** yang ditujukan bagi pengguna akhir, yaitu pegawai outsourcing BPJS Kesehatan pada berbagai posisi (Satpam, Office Boy, Driver, dan sebagainya). Panduan ini menjelaskan langkah demi langkah cara menggunakan aplikasi mulai dari login hingga menyelesaikan proses evaluasi.

## 1.2 Audiens

Dokumen ini ditujukan kepada:

- Pegawai outsourcing BPJS Kesehatan yang akan mengikuti evaluasi berkala.
- Pengguna baru yang pertama kali menggunakan aplikasi PENTAS.

## 1.3 Istilah Penting

| Istilah | Penjelasan |
|---|---|
| NPP | Nomor Pokok Pegawai — digunakan sebagai username saat login |
| Kategori | Pengelompokan besar jenis pegawai (contoh: TAD, Pegawai, Petugas Sentralisasi) |
| Sub-Kategori | Posisi spesifik pegawai di dalam kategori (contoh: Satpam, Office Boy, Driver) |
| Periode | Rentang waktu evaluasi (biasanya bulanan) |
| Materi | Bahan bacaan / video pembelajaran untuk periode berjalan |
| Test / JITU | Kuis evaluasi pilihan ganda |
| Do-Check | Sesi review / pembahasan jawaban |
| Rekap / Rekapin | Ringkasan hasil evaluasi |

# 2. Tentang Sistem PENTAS

PENTAS adalah sistem evaluasi pembelajaran BPJS Kesehatan yang menerapkan alur pembelajaran 4 tahap:

1. **Kupas Tuntas (Materi)** — Pengguna membaca / menonton materi pembelajaran.
2. **JITU (Test)** — Pengguna mengerjakan soal pilihan ganda.
3. **Do-Check** — Pengguna melihat kembali pembahasan jawaban setelah waktu test berakhir.
4. **Rekapin (Rekap)** — Ringkasan hasil final yang ditampilkan.

Setiap periode (bulan) akan memiliki kumpulan materi dan soal baru yang wajib diselesaikan oleh pengguna sesuai jadwal.

# 3. Persyaratan Sistem

Agar aplikasi berjalan optimal, pastikan hal-hal berikut:

- **Perangkat:** PC / laptop, tablet, atau smartphone.
- **Browser yang direkomendasikan:** Google Chrome, Microsoft Edge, Mozilla Firefox, atau Safari versi terbaru.
- **Koneksi internet:** stabil (minimal 1 Mbps) untuk menonton video materi.
- **JavaScript:** harus diaktifkan pada browser.
- **Cookies:** harus diizinkan untuk menjaga sesi login.

# 6. Login Pengguna

Proses login dilakukan dalam dua tahap: **pilih posisi** lalu **masukkan kredensial**.

## 6.1 Memilih Posisi

1. Dari Halaman Beranda, klik tombol **Masuk**.
2. Anda akan melihat halaman **"Masuk ke PENTAS"** dengan daftar Kategori.
3. Setiap kategori memiliki beberapa tombol posisi (Sub-Kategori) di dalamnya.
4. Klik salah satu posisi yang sesuai (misalnya: **Satpam**, **Office Boy**, **Driver**).

> *[Placeholder Gambar 6.1: Halaman pilih posisi]*

**Catatan:**
- Jika posisi ditandai dengan label **"Segera"** atau **"Segera Hadir"**, berarti posisi tersebut belum aktif. Hubungi admin jika Anda yakin posisi seharusnya sudah aktif.

## 6.2 Memasukkan Kredensial

Setelah memilih posisi, halaman login khusus sub-kategori akan muncul.

1. Masukkan **NPP** (Nomor Pokok Pegawai) Anda pada kolom pertama.
2. Masukkan **Password** pada kolom kedua.
3. (Opsional) Klik ikon mata di ujung kanan kolom password untuk menampilkan / menyembunyikan karakter password.
4. Klik tombol **Sign In** (berwarna hijau) untuk masuk.

> *[Placeholder Gambar 6.2: Form login sub-kategori]*

## 6.3 Jika Login Gagal

Apabila NPP atau password yang dimasukkan salah, akan muncul pesan kesalahan berwarna merah di atas tombol login (misal: *"NPP atau password salah"*).

**Langkah yang dapat dilakukan:**

- Periksa penulisan NPP (tanpa spasi).
- Periksa penulisan password (perhatikan huruf besar / kecil).
- Jika lupa password, hubungi Admin BPJS untuk reset password.

## 6.4 Ganti Posisi atau Kembali ke Beranda

Di bawah form login terdapat dua tautan:

- **Pilih Posisi Lain** — kembali ke halaman pilih posisi.
- **Beranda** — kembali ke halaman utama.

# 9. Membaca Materi

Tahap **Kupas Tuntas (Materi)** adalah tahap pertama pada setiap periode. Pengguna wajib menyelesaikan pembacaan materi sebelum bisa mulai mengerjakan test.

## 9.1 Membuka Halaman Materi

1. Dari Dashboard Sub-Kategori, klik kartu **Kupas Tuntas** atau tombol **Mulai Baca Materi**.
2. Halaman materi akan terbuka.

## 9.2 Elemen Halaman Materi

- **Header atas:** tombol **Kembali**, breadcrumb (Sub-Kategori > Materi), dan nama periode.
- **Progress Bar:** menampilkan posisi *"Materi X dari Y"* dan persentase penyelesaian.
- **Kartu Materi Utama** berisi:
  - Judul materi (header gradient ungu)
  - **Video Player** (jika materi berupa video) — mendukung embed YouTube / file video upload
  - Tombol **Baca PDF** (jika materi dilengkapi file PDF)
  - Konten teks materi (dapat berupa rich text / HTML)
- **Navigator Dot** di bawah konten — untuk melompat antar materi.
- **Panel Samping "Daftar Materi"** — daftar semua materi dengan ikon video / PDF.

## 9.3 Tombol Navigasi

| Tombol | Fungsi | Keterangan |
|---|---|---|
| **Sebelumnya** | Pindah ke materi sebelumnya | Nonaktif pada materi pertama |
| **Selanjutnya** | Pindah ke materi berikutnya | Tersedia di materi tengah |
| **Selesai Baca Materi** | Menandai materi selesai dibaca | Hanya muncul di materi terakhir |
| **Lanjut ke Quiz** | Menuju halaman test | Muncul setelah materi selesai |

## 9.4 Menyelesaikan Pembacaan Materi

1. Baca / tonton seluruh materi dari awal hingga akhir.
2. Pada materi terakhir, klik tombol **Selesai Baca Materi**.
3. Badge **"Selesai Dibaca"** akan muncul di bagian atas materi.
4. Klik **Lanjut ke Quiz** untuk pindah ke tahap Test.

**Catatan:** Anda tetap dapat membaca kembali materi kapan saja selama periode berjalan.

# 10. Mengerjakan Test / Quiz

Tahap **JITU (Test)** adalah tahap pengerjaan soal pilihan ganda. Test hanya bisa dikerjakan pada rentang waktu yang dijadwalkan oleh admin.

## 10.1 Memulai Test

1. Dari Dashboard Sub-Kategori, klik kartu **JITU** atau tombol **Mulai Test** (hanya aktif jika materi sudah selesai dan jadwal test sudah dimulai).
2. Halaman Test akan terbuka.

## 10.2 Elemen Halaman Test

- **Header atas (sticky):**
  - Tombol **X** untuk keluar
  - Nama periode test
  - Counter jawaban (*"X / Y terjawab"*)
  - Progress bar biru
- **Kartu Soal** (satu soal per tampilan):
  - Label **"Soal 1"** dan badge **"Dijawab"** (jika sudah dipilih)
  - Teks pertanyaan
  - 4 pilihan jawaban berlabel **A, B, C, D**
- **Tombol Navigasi Bawah:**
  - **Sebelumnya**
  - **Selanjutnya** / **Selesai & Submit** (pada soal terakhir)
- **Navigator Soal:** grid berisi nomor soal dengan kode warna:
  - **Hijau** = sudah dijawab
  - **Abu-abu** = belum dijawab
  - **Biru dengan ring** = soal sedang aktif

> *[Placeholder Gambar 10.1: Halaman Quiz dengan soal aktif]*

## 10.3 Cara Mengerjakan

1. Baca pertanyaan dengan teliti.
2. Klik salah satu pilihan jawaban (A, B, C, atau D). Jawaban akan **tersimpan otomatis** ke sistem.
3. Klik **Selanjutnya** untuk soal berikutnya, atau **Sebelumnya** untuk mengoreksi jawaban sebelumnya.
4. Anda juga dapat langsung lompat ke soal tertentu dengan mengklik nomor pada navigator soal di bawah.

**Penting:**
- Sistem menyimpan jawaban secara otomatis setiap kali Anda memilih opsi.
- Anda dapat mengubah jawaban selama belum menekan **Submit**.

## 10.4 Submit Test

1. Setelah seluruh soal selesai, klik tombol **Selesai & Submit** pada soal terakhir.
2. Modal konfirmasi akan muncul berisi ringkasan: total soal, jumlah sudah dijawab, jumlah belum dijawab.
3. Jika masih ada soal belum dijawab, akan ada peringatan berwarna kuning.
4. Klik **Ya, Submit** untuk mengirim jawaban, atau **Batal** untuk kembali mengoreksi.
5. Setelah submit berhasil, Anda akan diarahkan ke halaman Hasil.

> *[Placeholder Gambar 10.2: Modal konfirmasi submit]*

## 10.5 Peringatan Meninggalkan Halaman

Jika Anda mencoba menutup tab atau menekan tombol back browser saat test berjalan, akan muncul konfirmasi dari browser. Pastikan test sudah di-submit sebelum meninggalkan halaman.

# 11. Melihat Hasil Test dan Pembahasan

Setelah test selesai, Anda akan diarahkan ke halaman **Hasil Test**.

## 11.1 Tampilan Ringkasan Hasil

- **Skor Besar** di tengah (misal: **85**).
- **5 Emoji Rating** (😡 Sangat Buruk → 🤩 Sangat Baik) dengan warna sesuai skor:
  - ≥ 80: hijau (Sangat Baik)
  - 60 – 79: kuning (Baik)
  - 40 – 59: oranye (Cukup)
  - < 40: merah (Kurang)
- **4 Kartu Statistik:** Total Soal, Benar, Salah, Tidak Dijawab.
- **Bar Chart Horizontal:** distribusi jawaban (hijau / merah / abu).
- **Grid Navigator Soal:** hijau = benar, merah = salah, abu = tidak dijawab.
- **Tombol Lihat Pembahasan** (hanya tampil setelah waktu Do-Check aktif).

> *[Placeholder Gambar 11.1: Tampilan ringkasan hasil]*

## 11.2 Mode Pembahasan (Do-Check)

Pembahasan hanya dapat diakses setelah **waktu test berakhir** dan **admin mengaktifkan Do-Check** (sesuai jadwal).

Jika belum tersedia, akan muncul kotak informasi berwarna kuning:

> *"Pembahasan akan tersedia setelah waktu pengerjaan berakhir."*

### Melihat Pembahasan

1. Klik tombol **Lihat Pembahasan**.
2. Anda akan masuk ke mode review soal per soal.
3. Setiap soal akan menampilkan:
   - Warna header: **hijau** (benar), **merah** (salah), atau **abu** (tidak dijawab).
   - Pertanyaan.
   - Pilihan jawaban — yang **benar** diberi highlight hijau dengan label centang; yang Anda pilih namun salah diberi highlight merah.
   - Kotak **Pembahasan** berwarna biru berisi penjelasan jawaban.
4. Gunakan tombol **Sebelumnya** / **Selanjutnya** untuk navigasi, atau klik nomor soal pada navigator.
5. Klik **Selesai Review** atau **Kembali ke Ringkasan** untuk keluar dari mode pembahasan.

## 13.1 Mengakses Profil

## 13.2 Informasi yang Ditampilkan

Halaman profil terbagi menjadi beberapa kartu:

- **NPP** — ditampilkan dalam format monospace
- **Email**
- **Posisi**
- **Sub Kategori**

### Kartu Lokasi
- **Kedeputian Wilayah (Kepwil)**
- **Kantor Cabang (KC)**
- **Kantor Kabupaten (Kakab)**

> *[Placeholder Gambar 13.1: Halaman Profil]*

**Catatan:** Data di kedua kartu tersebut bersifat **hanya tampil (read-only)**. Jika terdapat kesalahan data, hubungi admin untuk pembaruan.

## 13.3 Ganti Password

Pada kartu **Ganti Password** (header oranye), lakukan langkah berikut:

1. Masukkan **Password Saat Ini**.
2. Masukkan **Password Baru** (minimal 6 karakter).
3. Masukkan kembali password baru pada **Konfirmasi Password Baru**.
4. Perhatikan **indikator kekuatan password** yang muncul:
   - **Terlalu pendek** — merah
   - **Lemah** — oranye
   - **Cukup** — kuning
   - **Kuat** — hijau
   - **Sangat Kuat** — hijau tua
5. Di bawah kolom konfirmasi akan muncul indikator:
   - ✔ **Password cocok** (hijau) atau
   - ✘ **Password tidak cocok** (merah)
6. Klik tombol **Simpan Password Baru**.
7. Jika berhasil, akan muncul pesan sukses selama 3 detik.

**Rekomendasi password kuat:**
- Minimal 8 karakter.
- Kombinasi huruf besar, huruf kecil, angka, dan simbol.

# 15. Pertanyaan Umum (FAQ)

**T: Saya lupa password, bagaimana cara meresetnya?**
J: Hubungi Admin BPJS Anda. Admin dapat melakukan reset password melalui halaman Kelola Users.

**T: Mengapa tombol "Mulai Test" tidak bisa diklik?**
J: Kemungkinan penyebab:
- Materi belum selesai dibaca seluruhnya.
- Jadwal test belum dimulai.
- Waktu test sudah berakhir.
- Test pada periode tersebut sudah pernah Anda kerjakan.

**T: Apakah jawaban saya hilang jika koneksi internet terputus?**
J: Tidak. Jawaban tersimpan otomatis di server setiap kali Anda memilih opsi. Setelah koneksi pulih, lanjutkan pengerjaan dari posisi terakhir.

**T: Bisakah saya membuka pembahasan sebelum waktu Do-Check?**
J: Tidak. Pembahasan hanya tersedia setelah periode test berakhir dan admin mengaktifkan Do-Check.

**T: Bagaimana mengganti data pribadi (nama, email, posisi)?**
J: Data tersebut hanya dapat diubah oleh Admin. Ajukan permintaan pembaruan data kepada Admin di kantor cabang Anda.

**T: Apakah saya bisa mengerjakan test dari HP?**
J: Ya, aplikasi mendukung tampilan mobile. Namun untuk pengalaman terbaik disarankan menggunakan PC / laptop.

# 16. Troubleshooting

## 16.1 Halaman Tidak Muncul / Blank

- Refresh halaman (tekan **F5** atau **Ctrl+R**).
- Bersihkan cache browser.
- Periksa koneksi internet Anda.
- Coba browser lain (Chrome, Edge, Firefox).

## 16.2 Login Tidak Berhasil

- Pastikan **Caps Lock** tidak aktif.
- Periksa kembali NPP (tanpa spasi, huruf kapital jika perlu).
- Jika tetap gagal, hubungi Admin.

## 16.3 Video Materi Tidak Bisa Diputar

- Periksa koneksi internet.
- Refresh halaman.
- Jika video tetap tidak tampil, hubungi Admin.

## 16.4 Tombol Submit Tidak Responsif

- Tunggu beberapa detik — sistem mungkin sedang memproses.
- Jika tetap tidak merespons, refresh halaman dan masuk kembali. Jawaban yang sudah tersimpan tidak akan hilang.

## 16.5 Keluar dari Sesi Secara Tidak Sengaja

Sistem akan otomatis men-logout pengguna setelah periode tertentu demi keamanan. Jika hal ini terjadi, cukup login ulang dengan NPP dan password Anda.
